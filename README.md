# Garden Concept – sajt

Statičan sajt za GitHub Pages. Otpremiti sve fajlove u koren repozitorijuma, pa Settings → Pages → Deploy from branch.

Pre objave:
1. Zameniti `https://VAS-DOMEN.rs` pravim domenom u svim `.html` fajlovima, `sitemap.xml` i `robots.txt`.
2. `main.js`: upisati Web3Forms ključ u `WEB3FORMS_KEY`.
3. `main.js`: upisati stvarno zauzete datume u `ZAUZETO` (trenutno su primeri).
4. Popuniti sve `[UGLASTE ZAGRADE]` podacima klijenta.
5. Posle objave prijaviti `sitemap.xml` u Google Search Console i otvoriti Google Business profil.
